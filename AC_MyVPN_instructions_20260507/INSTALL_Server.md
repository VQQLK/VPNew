# 🖥️ Инструкция по установке сервера MyVPN (Xray + VLESS + Reality)

## 1. Требования к VPS
- **ОС:** Ubuntu 20.04 / 22.04 или Debian 11 / 12 (рекомендуется Ubuntu 22.04)
- **Память:** минимум 512 MB RAM (комфортно — 1 GB)
- **Диск:** от 10 GB SSD/NVMe
- **Сеть:** 1 Гбит/с, безлимитный трафик (желательно)
- **Порты:** открыт 443 (TCP), а также 22 для SSH

3. Загрузка и запуск скрипта
bash
curl -O https://raw.githubusercontent.com/VQQLK/VPNew/main/AC_MyVPN_server_20260507/setup_xray.sh

4. Интерактивная настройка
Скрипт задаст несколько вопросов:

4.1 Внешний IP
Если автоматическое определение не сработало, введите IP вручную.

4.2 Роль сервера
1) Конечный (Exit) — обычный VPN-сервер.

2) Промежуточный (Entry/Relay) — проброс трафика на другой сервер (цепочка).
При выборе релея укажите IP, порт, UUID, публичный ключ, Short ID и SNI выходного сервера.

4.3 Тип транспорта
1) TCP — классический, совместим со всеми клиентами.

2) gRPC (HTTP/2) — маскировка под обычный веб-трафик, эффективнее обходит DPI.
Для gRPC дополнительно задаётся serviceName (по умолчанию «default»).

4.4 Onering-подобная защита
Защита от активного зондирования. Если включена, сервер принимает только клиентов с уникальным SNI.
Потребуется ввести:

Основной домен (любой уникальный идентификатор).

Домен-прикрытие (например, www.google.com) — на него будут перенаправлены все посторонние запросы.

Важно: сохраните основной домен — он понадобится в поле SNI на клиенте.

5. Результат установки
Клиентский JSON: /etc/xray/clients/client_config.json

VLESS-ссылка: /etc/xray/clients/vless_link.txt

Скопируйте конфиг к себе:

bash
scp root@ваш_ip:/etc/xray/clients/client_config.json .
6. Firewall (при необходимости)
bash

7. Проверка
bash
systemctl status xray
journalctl -u xray -f
8. Дополнительные рекомендации

Мониторинг: скрипт уже добавил cron-задачу на перезапуск каждые 5 минут.

Для максимальной защиты на клиенте: установите zapret (см. инструкцию к вашей ОС в папке instructions).

9. Устранение неполадок
Xray не стартует: journalctl -u xray -f

Клиент не подключается: проверьте совпадение публичного ключа (pbk), Short ID, SNI (особенно при активном Onering) и транспорта.

## 🛡️ Дополнительная защита: маскировка и десинхронизация

1. **Если сервер использует gRPC (HTTP/2)**, ваш трафик выглядит как обычный просмотр веб-страниц.  
   В клиенте выберите транспорт `grpc` и укажите `serviceName`, который вы получили от администратора сервера (обычно «default»).

2. **Защита от активного зондирования (Onering)**  
   Если администратор включил эту функцию, в поле `sni` следует ввести специальный домен (уникальный идентификатор), который он вам сообщил. Обычный сканер не сможет обнаружить ваш сервер.

3. **Обход пассивного DPI (рекомендовано для Роскомнадзора)**  
   Установите утилиту `zapret`, которая разрушает сигнатуры VPN-трафика:  
   - [Windows](https://github.com/bol-van/zapret-win-bundle)  
   - [Linux/macOS](https://github.com/bol-van/zapret)  
   Она не требует настройки сервера и работает прозрачно для всех приложений.
